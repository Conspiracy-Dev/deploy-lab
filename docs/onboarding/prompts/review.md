# Review a stable diff

```text
Review this DeployLab diff read-only for <architecture/SEO-CWV/tests/security>.
Use <contracts and paths>. Report findings with severity, file and evidence;
separate proven defects from questions. Do not edit files, broaden scope, or
claim browser proof without a real browser run.
```

Avoid: “Check if everything is good.” It does not define an acceptance surface
or distinguish a review from implementation.
