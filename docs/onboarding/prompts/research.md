# Research a bounded question

```text
Investigate whether <specific package or current code path> supports <need> in
DeployLab. Read the owning code first, use current vendor documentation for
public APIs, and return: observed facts, viable options, the smallest safe
recommendation, verification, and an explicit no-change option. Do not edit
files or install packages.
```

Avoid: “Research everything that could improve the app.” It has no decision,
time boundary, or evidence standard.
