# Open Graph и favicon DeployLab

Статус на 2026-11-15 — реализация и контейнерная проверка готовы к ревью
в ветке `codex/opengraph-favicon` от `3dc5ca7`. Открыта публичная приёмка.

## Goal

У всех страниц DeployLab единая обложка при отправке ссылки и чёрный
фирменный favicon. Заголовок и описание превью берутся из метаданных страницы.

## Non-goals

Область изменений — экспорт из Figma, метаданные Nuxt и доставка файлов.
Новые макеты и пакеты возможны при отдельной подтверждённой потребности.

## Constraints

- В Figma источник — [UI KIT](https://www.figma.com/design/0dto2dTdI7m3yyEelxxgDz/DeployLab--Copy-?node-id=141-98).
  Согласованные узлы указаны в [ADR](../decisions/opengraph-favicon.md).
- Приёмка охватывает Telegram, LinkedIn, Facebook, X, браузеры и Google Search.
- Коммит возможен после ревью и явного разрешения пользователя.

Дорожная карта — согласованные фреймы → проверенный экспорт → интеграция и
проверки Nuxt → контейнер и публичная приёмка → ревью. После каждого эпика
здесь фиксируется результат проверок и открытые пункты.

- Эпик 1 закрыт. Обложка и знак экспортированы из согласованных фреймов.
  Размеры PNG и ICO проверены, знак читается в масштабе 16 px.
- Эпик 2 закрыт. `pnpm quality:static` прошёл, включая 64 теста Vitest.
  Финальный Playwright-прогон на отдельном порту дал 31 успешный тест и
  5 пропусков по браузерному профилю. `pnpm generate` пререндерил 40 маршрутов.
  Chrome и WebKit подтвердили SEO-теги без JavaScript и декодирование трёх
  изображений. Проверены `robots.txt`, sitemap и `noindex` для 404.
  На одном из ранних прогонов упал тест поля UI Kit во время гидратации.
  На `main` наблюдалось такое же предупреждение Vue, восемь повторов
  проверки на `main` прошли.
- Эпик 3. Контейнерная проверка пройдена. Первый прогон показал, что Caddy
  отдавал `/favicon.ico` как `text/plain`. Для этого пути в обоих Caddyfile
  задан `image/vnd.microsoft.icon`, а smoke-тест проверяет заголовок.
  Повторный `pnpm test:docker:smoke` и `pnpm test:deployment:production-compose`
  прошли. Caddy отдал HTML с OG/X-тегами на `/` и `/privacy-policy`, а также
  все три файла с HTTP 200, ожидаемыми MIME и размерами. SHA-256 файлов
  совпал с рабочей копией. Production Caddyfile проверен в отдельном локальном
  HTTPS-контейнере, который вернул ICO с ожидаемым MIME и содержимым.
  Для внешних проверок нужен публичный HTTPS-адрес этой сборки.

## Verification

- Файлы — PNG 1200×630, PNG 96×96, ICO 32×32. Проверить вид в масштабе
  превью и маленький размер значка.
- HTML — получить `/` и `/privacy-policy` без JavaScript. Сверить
  единственные OG/X-теги и `rel="icon"`, абсолютные URL, наличие alt, MIME,
  размеры и сохранение текущих SEO-тегов каждой страницы.
- Сборка — сгенерировать сайт с тестовым HTTPS origin, проверить HTML,
  сохранение `robots.txt`, sitemap и 404, затем запросить ассеты по HTTP.
- Контейнер — запустить `pnpm test:docker:smoke` и сверить HTML и ассеты
  по HTTP через Caddy. Для production-профиля проверить ICO по локальному HTTPS.
- Клиенты — Chromium и Safari/WebKit, Telegram, [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/),
  [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) и
  X. Для Google проверить правила обхода и стабильный URL favicon.

## Risk and stop condition

- Для проверки превью внешними клиентами нужен согласованный публичный HTTPS
  с этой сборкой. Появление favicon в выдаче зависит от переобхода Google.
- Откат метаданных и файлов выполняется одной версией сайта.
