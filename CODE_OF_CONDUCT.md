# Code of conduct

DeployLab is a respectful, evidence-driven engineering space. Treat
contributors, reviewers, users, and automated-agent output with care.

## Expected behaviour

- Discuss code and decisions constructively and specifically.
- Make room for different experience levels and accessibility needs.
- Challenge assumptions, not people.
- Protect private data, credentials, and security reports.
- Accept review feedback and correct factual mistakes promptly.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, deliberate exposure of
private data, and knowingly disruptive or unsafe changes are not acceptable.

## Enforcement

Report concerns privately to the repository owner, Igor Shavlovsky. Reports are
handled discretely; the owner may request a correction, limit participation, or
remove access when necessary.
