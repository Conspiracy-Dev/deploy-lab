# Support

Use the repository issue templates for reproducible bugs and scoped feature
proposals. Include the expected result, actual result, environment, and the
smallest reproduction or relevant verification output.

Do not use public issues for credentials, private Figma links, production data,
or security vulnerabilities; see [SECURITY.md](SECURITY.md) instead.

For an architectural decision or a change that affects public contracts, state
the decision needed and the evidence that would resolve it. The project avoids
open-ended “investigate later” work without an owner-actionable next step.
